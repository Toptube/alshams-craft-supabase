# خريطة التطوير الشاملة لمنظومة الشمساوية (المرجع الدائم للاستكمال)

تم الاتفاق الكامل بين المستخدم وفريق الهندسة على هذه الخريطة لتنفيذها على مراحل متسلسلة بدون تكرار أو تضارب في قاعدة البيانات أو الكود.

---

## ✅ المرحلة 1 (قيد الإنجاز والاعتماد في هذا التحديث)
1. **لوحة تحكم صفحة الهبوط والشعارات في السوبر أدمن (`landing_cms`):**
   - تحكم شامل بكل نصوص وعناوين وأوصاف وأزرار صفحة الهبوط + بوابة الترحيب + الشريط العلوي (`سجل الآن`) + التذييل + الأسئلة الشائعة + حكايات الورش + قسم الجديد.
   - استوديو تغيير أيقونات وشعارات المنظومة الأربعة (**الشعار المكتوب/اللوجو**، **الأيقونة المربعة**، **شخصية صقر**، **شخصية شموسة**) مع عرض **الشكل الحالي لنسختي النهاري ☀️ والليلي 🌙** ورفع أي صورة من استوديو الهاتف + تفريغ تلقائي للخلفية لتصبح شفافة + ضغط ذكي (`WebP/PNG/SVG`).
2. **تفعيل الدخول السريع بحساب Google + إصلاح مسار «نسيت كلمة المرور»:**
   - ربط `ResetPasswordScreen` فعلياً داخل `App.tsx` ومعالجة حدث `PASSWORD_RECOVERY` وروابط الاستعادة (`?recovery=1` / `type=recovery` / `token_hash`) ومعالجة أخطاء انتهاء الرابط.
   - إضافة زر الدخول السريع بجوجل (`signInWithOAuth({ provider: 'google' })`) في شاشات الدخول والتسجيل وربطه بشاشة `CompleteWorkshopScreen` للمستخدمين الجدد.
3. **إعداد حزمة الـ `SQL` الموحدة والنهائية (مقسمة إلى 4 أجزاء متتالية في `/migrations/`):**
   - الجزء 1: `20261115_01_platform_cms_and_safe_alterations.sql`
   - الجزء 2: `20261115_02_platform_suppliers_accounts.sql`
   - الجزء 3: `20261115_03_supplier_catalog_b2b_and_finance.sql`
   - الجزء 4: `20261115_04_rls_security_and_atomic_sync_rpc.sql`

## ⏳ المرحلة 2 (التالية فور تنفيذ الـ SQL): مسار الموردين الكامل ولوحة المورد المستقلة
1. تطوير `Register.tsx` و `AuthGateway.tsx` و `TermsModal.tsx`:
   - بطاقة اختيار نوع الحساب: **أنا فنان (ورشة)** مقابل **أنا مورد خامات (متجر خامات)**.
   - حقول المورد: طبيعة البيع (`أونلاين / محل / مصنع`) + نظام التسعير (`قطاعي / جملة / الاثنان`) + أقسام التوريد الأربعة (`الحبال والنسيج`، `الخرز والتطريز`، `تشكيل الخامات الطينية والمركبة`، `الأخشاب`) مع قائمة جاهزة للخامات + زر «تحديد الكل» + «إضافة خامة».
   - شروط وميثاق الجودة ومنع الغش التجاري للموردين + إشعار تلقائي للسوبر أدمن وكل الورش عند انضمام مورد جديد.
2. عزل مساحة عمل المورد (`accountRole === 'supplier'`):
   - واجهة منزلية مخصصة للمورد (`SupplierHomeScreen`) + كتالوج ومخزن خامات المورد (`سعر جملة + حد أدنى للجملة` / `سعر قطاعي` / ألوان وسُمك / تفعيل المتجر والسوق).
   - لوحة تحكم متجر المورد المستقلة (ثيمات، عملات، كوبونات، روابط تواصل، QR).
   - صفحة عملاء المورد + صفحة أوردرات المورد بالفلتر الرباعي (`الكل | متجري | موردين الشمساوية | خارج المنظومة`) + خزينة وحسابات ومصروفات المورد.

## ⏳ المرحلة 3: «موردين الشمساوية» + زر «مورديني» في الورشة + التسميع الآلي للمخزون والخزينة
1. **منصة «موردين الشمساوية» (`/#/suppliers-market`):**
   - تصفح خامات الموردين حسب القسم ونظام الجملة والقطاعي، مع التبديل اللحظي التلقائي لسعر الجملة عند تجاوز الحد الأدنى للكمية.
2. **زر ودفتر «مورديني» داخل الورشة (`WorkshopHomeScreen` + `SidebarDrawer` تحت `ERP` + `SuppliersView`):**
   - الفلتر الرباعي (`الكل | موردين المنظومة | موردين الشمساوية | خارج المنظومة`) + بحث بالتخصص/الدولة/المحافظة + زر إعادة الطلب السريع من متجر المورد.
3. **التسميع الآلي المزدوج (`receive_b2b_supply_order`):**
   - اعتماد الاستلام من الورشة يرحّل الطلب مرة واحدة فقط (محمياً بقفل `inventory_synced_at`) ليحدث:
     - زيادة مخزن خامات الورشة بالمتوسط المرجح + فاتورة مشتريات + خصم من خزينة الورشة المختارة.
     - خصم مخزن المورد + تسجيل الورشة في عملاء المورد + إيداع صافي القيمة في خزينة المورد.

## ⏳ المرحلة 4: بطاقتي «العملاء» و«الموردين» وبناء «موردين الشمساوية» عند السوبر أدمن + ترقية «شموسة» والدليل
1. **لوحة السوبر أدمن:**
   - إضافة بطاقتي **«العملاء»** و**«الموردين»** بجانب بطاقة الورش مع فلتر **الورشة / الفنان** وعرض عمود الورشة وعمود الفنان في الجداول.
   - إضافة بطاقة وباني **«موردين الشمساوية»** (سحب وإفلات، كوبونات، بنرات، أوسمة الموردين، تقييم، تجميد/حظر/تظلمات).
2. **دليل الاستخدام + ترقية «شموسة»:**
   - بناء سجل التنقل والأزرار الموحد (`navigationRegistry`) المغذي لصفحة دليل الاستخدام ولمساعدة «شموسة».
   - ترقية «شموسة» لتصبح **المديرة التنفيذية للمنظومة كلها** (فنانين + موردين + سوبر أدمن) مع احترام العزل التام لبيانات كل حساب.
